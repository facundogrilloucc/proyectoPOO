# 🔧 Solución para Archivo .desktop en Linux

## ❌ Problema Identificado

El archivo `SistemaBancario.desktop` original tenía varios problemas:
1. Usaba `%d` que no es válido en archivos .desktop
2. La sintaxis de `Exec` no era compatible con todos los entornos de escritorio
3. No estaba marcado como "confiable" (requerido en GNOME/Fedora)

## ✅ Solución Implementada

### Archivos Creados:

#### 1. `lanzar.sh` (Nuevo Launcher Universal)
- **Propósito:** Script que detecta y usa el emulador de terminal disponible
- **Compatible con:**
  - gnome-terminal (GNOME/Fedora)
  - konsole (KDE)
  - xterm (Genérico)
  - xfce4-terminal (XFCE)
  - Terminal actual (fallback)

#### 2. `SistemaBancario.desktop` (Actualizado)
- **Cambio principal:** Ahora llama a `lanzar.sh` en lugar de `run.sh` directamente
- **Terminal:** Cambiado a `false` (el launcher abre su propia terminal)
- **Marcado como confiable:** Usando comando `gio`

## 🚀 Opciones de Ejecución (En Orden de Facilidad)

### **Opción 1: Script lanzar.sh (MÁS FÁCIL)** ⭐
```bash
./lanzar.sh
```
O **doble clic** en `lanzar.sh` desde el explorador de archivos

**Ventajas:**
- ✅ Abre una nueva terminal automáticamente
- ✅ Funciona en todos los entornos de escritorio Linux
- ✅ No requiere configuración adicional

### **Opción 2: Script run.sh (Tradicional)**
```bash
./run.sh
```
O desde el explorador **clic derecho → "Ejecutar en terminal"**

**Ventajas:**
- ✅ Usa la terminal actual
- ✅ Más simple

### **Opción 3: Archivo .desktop (Para Escritorio)**
**Doble clic** en `SistemaBancario.desktop`

**Si no funciona:**
1. **Marcar como confiable:**
   ```bash
   gio set SistemaBancario.desktop metadata::trusted true
   chmod +x SistemaBancario.desktop
   ```

2. **Permitir lanzamiento** (en GNOME):
   - Clic derecho en el archivo
   - "Permitir lanzar" o "Allow Launching"

3. **Verificar permisos:**
   ```bash
   ls -la SistemaBancario.desktop
   # Debe mostrar: -rwxr-xr-x
   ```

## 🔍 Diagnóstico de Problemas

### El .desktop no hace nada al hacer doble clic:

**Solución:**
```bash
# 1. Dar permisos
chmod +x SistemaBancario.desktop
chmod +x lanzar.sh
chmod +x run.sh

# 2. Marcar como confiable
gio set SistemaBancario.desktop metadata::trusted true

# 3. Verificar que funciona desde terminal
./lanzar.sh
```

### El .desktop pide "confiar" o "trust":
- Es normal en GNOME/Fedora
- Haz clic en "Trust and Launch" / "Confiar y Ejecutar"
- Esto solo pasa la primera vez

### Ninguna terminal se abre:
**Verifica que tienes un emulador de terminal:**
```bash
which gnome-terminal konsole xterm xfce4-terminal
```

Si ninguno está instalado:
```bash
# Fedora
sudo dnf install gnome-terminal

# Ubuntu/Debian
sudo apt install gnome-terminal
```
